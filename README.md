# Healthcare Classification with Cross-Validation

## Overview
This repository contains Python code for applying **machine learning algorithms** on healthcare datasets for classification and clustering. The project demonstrates how to use several algorithms to predict and classify healthcare-related data, with a focus on **cross-validation** to evaluate performance.

### Algorithms Used:
1. **Support Vector Machine (SVM)**  
2. **K-Nearest Neighbors (KNN)**  
3. **Bayesian Networks (BN)**  
4. **K-Means Clustering**  
5. **Decision Trees (Arbor Decision)**  

## Dataset Used
- **Dataset:** Healthcare data, which includes features like patient age, medical history, and diagnostic results.
